★ Memória & Legado — Xica Manicongo (Séc. XVI)

Recusando as roupas masculinas impostas pelo senhorio e mantendo as vestimentas femininas tradicionais de sua terra de origem, foi denunciada à Inquisição. É venerada hoje como o símbolo fundante da ancestralidade e resistência travesti no Brasil.

3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Algoritmo de binarização adaptativa de Sauvola ($15 \times 15$, $k=0.35$, $R=128$) com intercalação de ranhuras direcionais que simulam veios vegetais da tábua de corte. Contraste talhado em preto de fumo (`#131110`) e papel kraft envelhecido (`#D6C4A5`) com tarja de impacto entalhada.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Sauvola Local Threshold (w=15, k=0.35, R=128) + Modulação de Fibra de Madeira.

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Binarização Adaptativa Local de Sauvola (15x15)

Equação de Binarização Adaptativa de Sauvola: T(x, y) = m(x, y) * [ 1 + k * ( s(x, y) / R - 1 ) ] onde: - m(x, y): média local de luminância na janela 15x15 - s(x, y): desvio padrão local na janela 15x15 - k = 0.35: coeficiente empírico de agressividade de corte - R = 128: amplitude dinâmica de desvio padrão Pixel é preto se L(x, y) < T(x, y), caso contrário kraft queimado.

Particularidade do Preset: Textura cortante da goiva entalhando madeira de lei, papel kraft áspero e folhetos de cordel; homenagem à primeira travesti documentada do Brasil (século XVI).

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_xilogravura.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image
from scipy.ndimage import uniform_filter

def sauvola_threshold(gray: np.ndarray, window: int = 15, k: float = 0.35, R: float = 128.0) -> np.ndarray:
    mean = uniform_filter(gray.astype(np.float32), size=window)
    sq_mean = uniform_filter(gray.astype(np.float32)**2, size=window)
    std = np.sqrt(np.maximum(sq_mean - mean**2, 0.0))
    threshold = mean * (1.0 + k * (std / R - 1.0))
    return np.where(gray < threshold, 0, 255).astype(np.uint8)

def render_xilogravura(input_path: str, output_path: str):
    img = Image.open(input_path).convert('L')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    arr = np.array(img)
    # Aplica Sauvola
    bin_wood = sauvola_threshold(arr)
    h, w = bin_wood.shape
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [214, 196, 165] # Kraft Queimado #D6C4A5
    poster[bin_wood == 0] = [19, 17, 16] # Preto Fumo #131110
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

xilogravura_shader.glsl
// Fragment Shader Xilogravura
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    float l = dot(texture2D(u_tex, v_uv).rgb, vec3(0.299, 0.587, 0.114));
    vec3 colFumo  = vec3(0.075, 0.067, 0.063); // #131110
    vec3 colKraft = vec3(0.839, 0.769, 0.647); // #D6C4A5
    gl_FragColor = vec4(l < 0.48 ? colFumo : colKraft, 1.0);
}
