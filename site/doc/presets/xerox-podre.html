3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Implementa a matriz geométrica Bayer 8x8 (Ordered Dithering) com unsharp masking agressivo (3.2x), queima drástica dos níveis intermediários e faixa com distorções e artefatos determinísticos de fotocopiadora analógica (jitter de varredura lateral, riscos de cilindro com perda de toner e micro-cavidades de descolamento de pó). O resultado é a textura granulada e física de toner de carbono sobre celulose oxidada.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 640px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Unsharp Mask (r=2.0, k=3.0) + Queima de Meios-Tons (Levels 30-225).

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Bayer Ordered Dithering 8x8 + Artefatos LCG de Toner

Matriz Ordenada de Bayer 8x8 normalizada por 1/64: M8 = (1/64) * [ [ 0, 32, 8, 40, 2, 34, 10, 42], [48, 16, 56, 24, 50, 18, 58, 26], [12, 44, 4, 36, 14, 46, 6, 38], [60, 28, 52, 20, 62, 30, 54, 22], [ 3, 35, 11, 43, 1, 33, 9, 41], [51, 19, 59, 27, 49, 17, 57, 25], [15, 47, 7, 39, 13, 45, 5, 37], [63, 31, 55, 23, 61, 29, 53, 21] ] Artefatos de Toner: ruído pseudoaleatório determinístico por Linear Congruential Generator (LCG).

Particularidade do Preset: Simula cilindro de fotocopiadora desgastado, perda de toner vertical, poeira de carvão e papel jornal oxidado com micro-riscos.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_xerox_podre.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image, ImageFilter

BAYER_8X8 = np.array([
    [ 0, 32,  8, 40,  2, 34, 10, 42],
    [48, 16, 56, 24, 50, 18, 58, 26],
    [12, 44,  4, 36, 14, 46,  6, 38],
    [60, 28, 52, 20, 62, 30, 54, 22],
    [ 3, 35, 11, 43,  1, 33,  9, 41],
    [51, 19, 59, 27, 49, 17, 57, 25],
    [15, 47,  7, 39, 13, 45,  5, 37],
    [63, 31, 55, 23, 61, 29, 53, 21]
], dtype=np.float32) / 64.0

def bayer_dither_8x8(gray: np.ndarray) -> np.ndarray:
    h, w = gray.shape
    norm = gray.astype(np.float32) / 255.0
    tiled_bayer = np.tile(BAYER_8X8, (int(np.ceil(h/8)), int(np.ceil(w/8))))[:h, :w]
    return np.where(norm >= tiled_bayer, 255, 0).astype(np.uint8)

def render_xerox_podre(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((640, int(round(h * 640 / w))), Image.Resampling.LANCZOS)
    gray = img.convert('L')
    blur = gray.filter(ImageFilter.BoxBlur(2.0))
    arr_gray = np.array(gray, dtype=np.float32)
    unsharp = np.clip(arr_gray + 3.0 * (arr_gray - np.array(blur, dtype=np.float32)), 0, 255)
    levels = np.clip((unsharp - 30.0) / 195.0 * 255.0, 0, 255)
    dithered = bayer_dither_8x8(levels)
    h, w = dithered.shape
    # Aplica riscos verticais de toner (cilindro gasto)
    rng = np.random.default_rng(seed=42) # determinístico
    line_noise = (rng.random(w) < 0.03).astype(np.uint8)
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [245, 242, 235] # Papel Oxidado #F5F2EB
    mask_dark = (dithered == 0) | (line_noise[np.newaxis, :] == 1)
    poster[mask_dark] = [28, 25, 23] # Toner #1C1917
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

xerox_podre_shader.glsl
// Fragment Shader Xerox Podre
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
const mat4 b4 = mat4(0.0, 8.0, 2.0, 10.0, 12.0, 4.0, 14.0, 6.0, 3.0, 11.0, 1.0, 9.0, 15.0, 7.0, 13.0, 5.0) / 16.0;
void main() {
    vec4 c = texture2D(u_tex, v_uv);
    float l = dot(c.rgb, vec3(0.299, 0.587, 0.114));
    vec2 coord = mod(gl_FragCoord.xy, 4.0);
    float threshold = b4[int(coord.x)][int(coord.y)];
    vec3 colToner = vec3(0.11, 0.098, 0.09); // #1C1917
    vec3 colPapel = vec3(0.96, 0.949, 0.92); // #F5F2EB
    gl_FragColor = vec4(l >= threshold ? colPapel : colToner, 1.0);
}
