3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Algoritmo de corrupção analógica determinística: jitter senoidal de linhas com saltos abruptos de fase, aberração cromática com dispersão planar de canais R e B (±4px), barra de perda de sincronismo vertical (V-Hold de 12px) e entrelaçamento de scanlines luminosas em tons de ciano CRT e vermelho aberração.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Deslocamento Horizontal Senoidal + Desacoplamento de Canais R/B (+-4px) + Perda de V-Hold.

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Sync Jitter Senoidal + Aberração Cromática R/B + V-Hold Roll

Equação de Sync Jitter Horizontal: dx(y) = 4.0 * sin(y * 0.12) + 12.0 * (rand(y) < 0.04) Aberração Cromática Desacoplada: R(x, y) = Canal_R(x + 4, y) G(x, y) = Canal_G(x, y) B(x, y) = Canal_B(x - 4, y) Barra Horizontal V-Hold: Inversão total de fase a cada ciclo vertical periódico.

Particularidade do Preset: Homenagem à advogada pioneira Robeyoncé Lima e à televisão pirata dos anos 80/90; aberração cromática analógica e perda periódica de sincronismo vertical.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_glitch_crt.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image

def render_glitch_crt(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    arr = np.array(img, dtype=np.uint8)
    h, w, c = arr.shape
    out = np.zeros_like(arr)
    # 1. Aberração cromática desacoplada R/B
    shift = 4
    out[:, shift:, 0] = arr[:, :-shift, 0] # Vermelho avança
    out[:, :, 1] = arr[:, :, 1]            # Verde estável
    out[:, :-shift, 2] = arr[:, shift:, 2] # Azul recua
    # 2. Sync Jitter horizontal senoidal
    for y in range(h):
        offset = int(round(5.0 * np.sin(y * 0.15)))
        out[y] = np.roll(out[y], offset, axis=0)
    # 3. Barra de V-Hold roll com inversão
    vhold_y = int(h * 0.45)
    out[vhold_y:vhold_y+30] = 255 - out[vhold_y:vhold_y+30]
    Image.fromarray(out).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

glitch_crt_shader.glsl
// Fragment Shader Glitch CRT
precision mediump float;
uniform sampler2D u_tex;
uniform float u_time;
varying vec2 v_uv;
void main() {
    vec2 uv = v_uv;
    // Jitter horizontal senoidal
    uv.x += sin(uv.y * 40.0) * 0.005;
    float r = texture2D(u_tex, uv + vec2(0.006, 0.0)).r;
    float g = texture2D(u_tex, uv).g;
    float b = texture2D(u_tex, uv - vec2(0.006, 0.0)).b;
    gl_FragColor = vec4(r, g, b, 1.0);
}
