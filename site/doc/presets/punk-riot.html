1. Memorial Histórico & Contexto Contracultural

Inspirado nos primeiros zines punks de 1976–1977 (como o lendário Sniffin' Glue de Mark Perry e os panfletos colados com fita durex nas ruas de Londres e Nova York), bem como nos fanzines anarcopunks dos anos 80 em São Paulo, Olinda e Brasília. Os zines eram feitos cortando fotos de jornais com estilete, colando manchetes com letras de tamanhos desconexos e fotocopiando em máquinas roubadas na calada da noite.

★ Memória & Legado — Claudia Wonder (1955–2010)

Memória & Legado — Claudia Wonder (1955–2010): Cantora, atriz, escritora e ícone definitivo da noite underground e punk paulistana dos anos 80. Liderou a lendária banda de rock Claudia Wonder & Os Vândalos, atuou no cinema marginal, compôs hinos da noite e publicou crônicas afiadas. Em plena ditadura militar e transição democrática, Claudia tomou a atitude DIY (Faça Você Mesma) do punk para fundar a visibilidade travesti na música independente brasileira, unindo jaquetas de couro com tachas, poesia debochada e resistência intransigente contra a violência policial.

3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Utiliza o algoritmo de Atkinson Dither (desenvolvido por Bill Atkinson na Apple). Diferente do Floyd-Steinberg tradicional que espalha 100% do erro residual, o Atkinson descarta 25% do erro propositalmente. Isso cria zonas de alto contraste limpas, realçando olhos, ossos e silhuetas escuras contra fundo vermelho vivo, com letras vazadas dentro de tarjas pretas maciças.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Unsharp Mask (r=1.5, k=2.5) + Queima de Níveis (Min=15, Max=240).

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Atkinson Dithering (75% erro, descarte 25%)

[ Pixel Atual: * ] [+1, 0]: +1/8 [+2, 0]: +1/8 [-1, +1]: +1/8 [ 0, +1]: +1/8 [+1, +1]: +1/8 [ 0, +2]: +1/8 Soma total do erro propagado: 6/8 = 75% Fração descartada para manter alto contraste: 2/8 = 25%

Particularidade do Preset: Descarte de 25% do erro residual para eliminar ruído em brancos e negros profundos; tarja preta de choque com letras vazadas e fundo vermelho vivo.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_punk_riot.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image, ImageFilter

def atkinson_dither(gray: np.ndarray) -> np.ndarray:
    h, w = gray.shape
    buf = gray.astype(np.float32)
    out = np.zeros((h, w), dtype=np.uint8)
    for y in range(h):
        for x in range(w):
            val = buf[y, x]
            q = 255.0 if val >= 128.0 else 0.0
            out[y, x] = int(q)
            err = (val - q) / 8.0
            if x + 1 < w: buf[y, x + 1] += err
            if x + 2 < w: buf[y, x + 2] += err
            if y + 1 < h:
                if x - 1 >= 0: buf[y + 1, x - 1] += err
                buf[y + 1, x] += err
                if x + 1 < w: buf[y + 1, x + 1] += err
            if y + 2 < h: buf[y + 2, x] += err
    return out

def render_punk_riot(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    gray = img.convert('L')
    blur = gray.filter(ImageFilter.BoxBlur(1.5))
    arr_gray = np.array(gray, dtype=np.float32)
    arr_unsharp = np.clip(arr_gray + 2.5 * (arr_gray - np.array(blur, dtype=np.float32)), 0, 255)
    levels = np.clip((arr_unsharp - 15.0) / 225.0 * 255.0, 0, 255)
    dithered = atkinson_dither(levels)
    h, w = dithered.shape
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [255, 0, 51] # Fundo Vermelho #FF0033
    poster[dithered == 0] = [0, 0, 0] # Sujeito Preto
    poster[(dithered == 255) & (arr_gray < 225)] = [255, 255, 255] # Realces Brancos
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

punk_riot_shader.glsl
// Fragment Shader Punk Riot
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    vec4 c = texture2D(u_tex, v_uv);
    float l = dot(c.rgb, vec3(0.299, 0.587, 0.114));
    l = clamp((l - 0.06) / 0.88, 0.0, 1.0);
    if (l < 0.4) gl_FragColor = vec4(0.0, 0.0, 0.0, 1.0);
    else if (l > 0.85) gl_FragColor = vec4(1.0, 0.0, 0.2, 1.0);
    else gl_FragColor = vec4(1.0, 1.0, 1.0, 1.0);
}
