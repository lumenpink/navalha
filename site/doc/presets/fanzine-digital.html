2. Paleta Cromática Canônica & Mapeamento

O preset reduz estritamente o espaço de cores contínuo da imagem para a seguinte paleta canônica indexada:

HEX: #001188
Amarelo CRT
HEX: #FFEE00
Branco Puro
HEX: #FFFFFF

3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Quantização matricial com retícula Bayer 8x8 em fundo azul ultramarino (`#001188`) associada a tarjas contrastantes em amarelo elétrico CRT (`#FFEE00`). O sujeito preserva o enquadramento fotográfico pleno sem guilhotina e adquire a estética inconfundível dos gráficos digitais dos primeiros sistemas de rede.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 640px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Unsharp (r=1.5, k=2.0) + Bayer 8x8.

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Bayer 8x8 Monocromático Cyber-BBS

Matriz Bayer 8x8 normalizada de quantização indexada sobre paleta de alta saturação: Azul Ultramarino #001188, Amarelo Fanzine #FFEE00 e Branco Puro #FFFFFF.

Particularidade do Preset: Homenagem às publicações digitais distribuídas em disquetes e BBSs nos anos 90, literatura de guerrilha e ativismo.

Etapa 3.4: Prensagem Tipográfica & Ondulação Scanner de Mão

Efeito Diferenciado de Tarja: Deformação ondulada senoidal contínua (wave_amplitude = 6.0 px, wave_wavelength = 110.0 px), simulando a puxada irregular de scanners manuais portáteis dos anos 90. A fase da onda é calculada a partir da semente da imagem com hash FNV-1a (veja a documentação no Motor de Determinismo & Sementes).

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_fanzine_digital.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image

BAYER_8X8 = np.array([
    [ 0, 32,  8, 40,  2, 34, 10, 42],
    [48, 16, 56, 24, 50, 18, 58, 26],
    [12, 44,  4, 36, 14, 46,  6, 38],
    [60, 28, 52, 20, 62, 30, 54, 22],
    [ 3, 35, 11, 43,  1, 33,  9, 41],
    [51, 19, 59, 27, 49, 17, 57, 25],
    [15, 47,  7, 39, 13, 45,  5, 37],
    [63, 31, 55, 23, 61, 29, 53, 21]
], dtype=np.float32) / 64.0

def render_fanzine_digital(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((640, int(round(h * 640 / w))), Image.Resampling.LANCZOS)
    gray = np.array(img.convert('L'), dtype=np.float32) / 255.0
    h, w = gray.shape
    tiled = np.tile(BAYER_8X8, (int(np.ceil(h/8)), int(np.ceil(w/8))))[:h, :w]
    dither = np.where(gray >= tiled, 1, 0)
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [0, 17, 136] # Azul #001188
    poster[dither == 1] = [255, 238, 0] # Amarelo #FFEE00
    poster[gray > 0.85] = [255, 255, 255] # Branco #FFFFFF
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

fanzine_digital_shader.glsl
// Fragment Shader Fanzine Digital
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    float l = dot(texture2D(u_tex, v_uv).rgb, vec3(0.299, 0.587, 0.114));
    vec3 colAzul = vec3(0.0, 0.067, 0.533);
    vec3 colAmarelo = vec3(1.0, 0.933, 0.0);
    vec3 colBranco = vec3(1.0, 1.0, 1.0);
    if (l < 0.4) gl_FragColor = vec4(colAzul, 1.0);
    else if (l < 0.8) gl_FragColor = vec4(colAmarelo, 1.0);
    else gl_FragColor = vec4(colBranco, 1.0);
}
