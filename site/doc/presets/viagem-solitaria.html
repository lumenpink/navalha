1. Memorial Histórico & Contexto Contracultural

Inspirado na estética documental dos manuscritos e fichários datilografados em máquinas Olivetti durante os anos 70 e 80. 3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Difusão bidimensional Floyd-Steinberg de alta densidade associada a um recorte cirúrgico de silhueta (threshold 0.82) e gama rebaixada (0.85). A fusão do sépia escuro com o ocre kraft reproduz a granulação tátil de documentos antigos arquivados sob sigilo.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 640px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Unsharp Suave (r=1.2, k=1.8) + Queima Suave (Levels 10-245).

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Floyd-Steinberg Dithering em Serpentina Bidirecional

Matriz Floyd-Steinberg em Serpentina Alternada: Varredura Esquerda->Direita: [ * ] 7/16 3/16 5/16 1/16 Varredura Direita->Esquerda: 7/16 [ * ] 1/16 5/16 3/16 Propaga 100% do erro residual eliminando artefatos unidirecionais.

Particularidade do Preset: Textura de fita de máquina de escrever dos anos 70, papel kraft e sépia queimado; homenagem ao primeiro homem trans operado no Brasil.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_viagem_solitaria.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image, ImageFilter

def floyd_steinberg_serpentine(gray: np.ndarray) -> np.ndarray:
    h, w = gray.shape
    buf = gray.astype(np.float32)
    out = np.zeros((h, w), dtype=np.uint8)
    for y in range(h):
        left_to_right = (y % 2 == 0)
        xs = range(w) if left_to_right else range(w - 1, -1, -1)
        for x in xs:
            val = buf[y, x]
            q = 255.0 if val >= 128.0 else 0.0
            out[y, x] = int(q)
            err = val - q
            if left_to_right:
                if x + 1 < w: buf[y, x + 1] += err * (7/16)
                if y + 1 < h:
                    if x - 1 >= 0: buf[y + 1, x - 1] += err * (3/16)
                    buf[y + 1, x] += err * (5/16)
                    if x + 1 < w: buf[y + 1, x + 1] += err * (1/16)
            else:
                if x - 1 >= 0: buf[y, x - 1] += err * (7/16)
                if y + 1 < h:
                    if x + 1 < w: buf[y + 1, x + 1] += err * (3/16)
                    buf[y + 1, x] += err * (5/16)
                    if x - 1 >= 0: buf[y + 1, x - 1] += err * (1/16)
    return out

def render_viagem_solitaria(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((640, int(round(h * 640 / w))), Image.Resampling.LANCZOS)
    gray = img.convert('L')
    blur = gray.filter(ImageFilter.BoxBlur(1.2))
    arr_gray = np.array(gray, dtype=np.float32)
    unsharp = np.clip(arr_gray + 1.8 * (arr_gray - np.array(blur, dtype=np.float32)), 0, 255)
    levels = np.clip((unsharp - 10.0) / 235.0 * 255.0, 0, 255)
    dithered = floyd_steinberg_serpentine(levels)
    h, w = dithered.shape
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [200, 168, 112] # Papel Kraft #C8A870
    poster[dithered == 0] = [43, 29, 12] # Tinta Carbono #2B1D0C
    poster[(dithered == 255) & (arr_gray < 230)] = [245, 235, 225] # Branco Fita #F5EBE1
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

viagem_solitaria_shader.glsl
// Fragment Shader Viagem Solitária
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    vec4 c = texture2D(u_tex, v_uv);
    float l = dot(c.rgb, vec3(0.299, 0.587, 0.114));
    vec3 colCarbono = vec3(0.169, 0.114, 0.047); // #2B1D0C
    vec3 colKraft   = vec3(0.784, 0.659, 0.439); // #C8A870
    vec3 colFita    = vec3(0.961, 0.922, 0.882); // #F5EBE1
    if (l < 0.45) gl_FragColor = vec4(colCarbono, 1.0);
    else if (l > 0.85) gl_FragColor = vec4(colFita, 1.0);
    else gl_FragColor = vec4(colKraft, 1.0);
}
