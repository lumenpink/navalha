1. Contexto Cultural & Tributo

Tributo: Jaqueline Gomes de Jesus (Transfeminismo Negro & Resistência Comunitária)

Professora universitária, psicóloga, escritora e militante histórica dos direitos humanos de pessoas trans e travestis no Brasil. Com atuação seminal na ABGLT e na ANTRA, Jaqueline é autora de obras teóricas, cartilhas, boletins e zines comunitários que articulam transfeminismo, negritude e emancipação coletiva através da circulação autogestionária da palavra impressa.

Os fanzines anarquistas são manifestações máximas da autonomia gráfica: produzidos inteiramente sem editores, censores ou financiamento comercial. Folhas A4 dobradas em A5, perfuradas e fixadas por dois grampos metálicos na lombada esquerda, distribuídas em manifestações e centros sociais autônomos.

A tipografia stencil (letras vazadas sustentadas por pontes mecânicas) surge da urgência de reproduzir cartazes e faixas de rua com spray e rolinho de tinta em segundos, antes da chegada da polícia.

2. Especificação Técnica & Matemática

O motor navalha-core processa o preset Anarco-Zine através dos seguintes parâmetros:

  • Downsampling Espacial: Resolução física de 640px (simulando boletim de bolso A5).
  • Retícula Mecânica (Halftone Screening): Retícula de meio-tom analógica com ângulo de 45° e tamanho de célula cell_size = 5px, simulando retículas de chapa offset barata.
  • Grampos Físicos de Fanzine: Injeção determinística de marcas de grampos metálicos (DamageEffect::Grampo) na borda esquerda simulando dobra de fanzine.
  • Adesivo Anarquista: Sticker do símbolo da anarquia Ⓐ com acabamento de borda picotada (StickerKind::Anarchy com StickerBorder::Picote).
// Equação da Retícula de Meio-Tom em 45 Graus:
u = x · cos(45°) - y · sin(45°)
v = x · sin(45°) + y · cos(45°)
dist = hypot(mod(u, cell_size) - cell_size/2, mod(v, cell_size) - cell_size/2)
ponto = dist < (1.0 - luminancia) · (cell_size / 2 · √2)

5. Guia de Reimplementação Agnóstica

Código autocontido em Python 3 com NumPy e Pillow implementando a retícula rotacionada de halftone na paleta Anarco-Zine:

reimplement_anarco_zine.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image

def halftone_45(gray_img, cell_size=5):
    h, w = gray_img.shape
    y_idx, x_idx = np.indices((h, w))
    rad = np.radians(45.0)
    cos_a, sin_a = np.cos(rad), np.sin(rad)
    
    u = x_idx * cos_a - y_idx * sin_a
    v = x_idx * sin_a + y_idx * cos_a
    
    mod_u = np.mod(u, cell_size) - cell_size / 2.0
    mod_v = np.mod(v, cell_size) - cell_size / 2.0
    dist = np.hypot(mod_u, mod_v)
    
    lum = gray_img.astype(np.float32) / 255.0
    max_r = (cell_size / 2.0) * np.sqrt(2.0)
    dot_r = (1.0 - lum) * max_r
    return np.where(dist < dot_r, 0, 255).astype(np.uint8)

def render_anarco_zine(input_path: str, output_path: str):
    img = Image.open(input_path).convert('L')
    w, h = img.size
    img = img.resize((640, int(round(h * 640 / w))), Image.Resampling.LANCZOS)
    arr = np.array(img)
    screened = halftone_45(arr, cell_size=5)
    
    h, w = screened.shape
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [214, 206, 189] # Kraft Fanzine
    poster[screened == 0] = [10, 10, 10] # Preto Anarquia
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

anarco_zine_shader.glsl
// Fragment Shader Anarco-Zine Halftone
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;

void main() {
    vec2 pos = v_uv * vec2(640.0, 880.0);
    float angle = 0.785398; // 45 graus
    mat2 rot = mat2(cos(angle), -sin(angle), sin(angle), cos(angle));
    vec2 rot_pos = rot * pos;
    vec2 grid = fract(rot_pos / 5.0) - 0.5;
    float dist = length(grid);
    
    float lum = dot(texture2D(u_tex, v_uv).rgb, vec3(0.299, 0.587, 0.114));
    float dot_size = (1.0 - lum) * 0.707;
    
    vec3 colKraft = vec3(0.839, 0.808, 0.741); // #D6CEBD
    vec3 colPreto = vec3(0.039, 0.039, 0.039); // #0A0A0A
    
    gl_FragColor = vec4(dist < dot_size ? colPreto : colKraft, 1.0);
}
