1. Memorial Histórico & Contexto Contracultural

A Risografia (inventada pela Riso Kagaku Corporation no Japão nos anos 80) foi adotada por artistas independentes no mundo inteiro por sua textura tátil única. Na impressora Riso, cada cor é física e independente, passando por um tambor de malha que deposita tinta pura com pontos mecânicos visíveis.

3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Algoritmo de Halftone Analógico a 45 graus, simulando o comportamento de retículas de chapa física de jornal e silk-screen. As altas luzes preservam o amarelo elétrico, enquanto os meios-tons e sombras são sustentados pelo rosa fluorescente e azul royal.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Separação Cromática de Cilindros + Halftone 45°.

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Halftone Analógico 45° Circular

Função de Ponto Halftone Circular em Grade Rotacionada a 45°: u = x * cos(45°) - y * sin(45°) v = x * sin(45°) + y * cos(45°) Raio da célula de meio-tom R = cell_size / 2. Distância do centro da célula: d = sqrt((mod(u, cell_size) - R)^2 + (mod(v, cell_size) - R)^2) O ponto é preenchido se d <= R * sqrt(1.0 - luminancia).

Particularidade do Preset: Retícula mecânica física com pontos de impressão analógicos e sobreposição de 3 camadas vibrantes (Azul, Rosa Fluo, Amarelo).

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_risografia.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image

def render_risografia(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    gray = np.array(img.convert('L'), dtype=np.float32) / 255.0
    h, w = gray.shape
    cell = 6.0
    rad = cell / 2.0
    y_idx, x_idx = np.indices((h, w))
    # Rotação 45 graus
    u = (x_idx - y_idx) * 0.707106
    v = (x_idx + y_idx) * 0.707106
    cu = np.mod(u, cell) - rad
    cv = np.mod(v, cell) - rad
    dist = np.sqrt(cu*cu + cv*cv)
    dot_radius = rad * np.sqrt(np.clip(1.0 - gray, 0.0, 1.0))
    dots = dist <= dot_radius
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [255, 242, 0] # Amarelo Riso #FFF200
    poster[dots] = [0, 56, 168]  # Azul Riso #0038A8
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

risografia_shader.glsl
// Fragment Shader Risografia 45°
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    float l = dot(texture2D(u_tex, v_uv).rgb, vec3(0.299, 0.587, 0.114));
    vec2 p = gl_FragCoord.xy;
    vec2 rot = vec2(p.x - p.y, p.x + p.y) * 0.7071;
    vec2 cell = mod(rot, 6.0) - 3.0;
    float dist = length(cell);
    float r = 3.0 * sqrt(clamp(1.0 - l, 0.0, 1.0));
    vec3 colAzul = vec3(0.0, 0.22, 0.659);
    vec3 colAmarelo = vec3(1.0, 0.949, 0.0);
    gl_FragColor = vec4(dist <= r ? colAzul : colAmarelo, 1.0);
}
