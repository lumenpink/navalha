1. Contexto Cultural & Tributo

Tributo: Marina Mathey (Show TRAVA / Cena Independente)

Cantora, compositora, atriz e performer travesti. Seu espetáculo e disco autoral TRAVA canalizam a fúria visceral, a desobediência e a poesia eletrônica underground contra a hipocrisia e a transfobia. Artista multidisciplinar da cena marginal independente de São Paulo, Marina une atitude crua de garagem, sintetizadores estridentes e fita demo em um manifesto vivo de resistência trans.

O movimento punk no ABC Paulista nasceu nos bairros fabris metalúrgicos sob a poeira de carvão e a fumaça de chaminés industriais. Sem acesso a estúdios convencionais ou grandes gravadoras, jovens operários gravavam seus próprios ensaios em fitas K7 cassete de baixo custo, reproduzidas e passadas de mão em mão nas saídas de fábricas e estações de trem.

Os encartes das fitas eram compostos através de recorte manual com gilete, colagem com fita adesiva amarelada e cópias de cópias de fotocopiadoras cansadas, gerando um contraste de pretos chapados e brancos queimados, pontuados pelo vermelho óxido característico dos galpões metalúrgicos.

2. Especificação Técnica & Matemática

O motor navalha-core processa o preset Punk 80 BR através dos seguintes parâmetros rígidos e determinísticos:

  • Downsampling Espacial: Resolução física de 720px (largura fixa mantendo a proporção original).
  • Realce de Bordas (Unsharp Mask): Raio de convolução r = 2, força de corte strength = 3.2 (destaque agressivo de contornos antes da retícula).
  • Queima de Níveis: Ponto de sombra (shadow cutoff) em 0.15, altas luzes (highlight cutoff) em 0.85, gama 1.0.
  • Algoritmo de Dither: Difusão de erro clássica de Atkinson (preservando 75% da energia do erro para criar o grão pontilhado do xerox de encarte de cassete).
  • Intervenção Física: Sticker procedural de fita cassete K7 (StickerKind::Cassette) e rasgo de papel (DamageEffect::Rasgo).

5. Guia de Reimplementação Agnóstica

Código autocontido em Python 3 com NumPy e Pillow implementando o dither Atkinson na paleta Punk 80 BR:

reimplement_punk_80_br.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image

PALETTE = np.array([
    [20, 20, 20],     # #141414 Preto Asfalto
    [166, 43, 43],    # #A62B2B Vermelho Óxido
    [230, 226, 212],  # #E6E2D4 Branco Papel K7
], dtype=np.float32)

def find_nearest_color(pixel):
    dists = np.sum((PALETTE - pixel)**2, axis=1)
    return PALETTE[np.argmin(dists)]

def atkinson_dither(img_arr):
    h, w, c = img_arr.shape
    arr = img_arr.astype(np.float32)
    for y in range(h):
        for x in range(w):
            old_p = arr[y, x].copy()
            new_p = find_nearest_color(old_p)
            arr[y, x] = new_p
            err = (old_p - new_p) / 8.0
            for dx, dy in [(1, 0), (2, 0), (-1, 1), (0, 1), (1, 1), (0, 2)]:
                nx, ny = x + dx, y + dy
                if 0 <= nx < w and 0 <= ny < h:
                    arr[ny, nx] += err
    return np.clip(arr, 0, 255).astype(np.uint8)

def render_punk_80_br(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    arr = np.array(img)
    dithered = atkinson_dither(arr)
    Image.fromarray(dithered).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

punk_80_br_shader.glsl
// Fragment Shader Punk 80 BR
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;

void main() {
    vec3 c = texture2D(u_tex, v_uv).rgb;
    float l = dot(c, vec3(0.299, 0.587, 0.114));
    vec3 colAsfalto = vec3(0.078, 0.078, 0.078); // #141414
    vec3 colOxido   = vec3(0.651, 0.169, 0.169); // #A62B2B
    vec3 colPapel   = vec3(0.902, 0.886, 0.831); // #E6E2D4
    
    vec3 outCol = l < 0.35 ? colAsfalto : (l < 0.68 ? colOxido : colPapel);
    gl_FragColor = vec4(outCol, 1.0);
}
