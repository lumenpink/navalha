3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Algoritmo de reprodução capilar: inversão de densidade óptica em papel manilha amarelado (`#F4EFE6`), retícula Bayer 4x4 e sangramento morfológico simulando o vazamento do solvente alcoólico (dispersão em raio de 1px nas áreas com saturação superior a 70%), com bordas em picote de estêncil manual.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Inversão de Densidade de Tinta + Bayer 4x4 + Dilatação Euclidiana de 1px.

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Densidade Invertida + Bayer 4x4 + Sangramento Morfológico

Cálculo de Tinta no Mimeógrafo a Álcool: Tinta = 255 - Luminância. A retícula Bayer 4x4 recebe dilatação morfológica euclidiana de raio 1px para simular o sangramento da anilina líquida no papel manilha absorvente. Paleta: Manilha #F4EFE6, Violeta Metil #432C7A, Anilina #2A1954.

Particularidade do Preset: Cheiro de álcool e fanzines de escola e panfletos clandestinos; sangramento suave nas bordas das letras sobre papel poroso manilha.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_mimeografo.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image, ImageFilter

def render_mimeografo(input_path: str, output_path: str):
    img = Image.open(input_path).convert('L')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    arr = np.array(img, dtype=np.float32)
    # Inverte densidade: mais escuro = mais tinta violeta
    tinta = np.clip(255.0 - arr, 0, 255)
    # Sangramento morfológico
    img_tinta = Image.fromarray(tinta.astype(np.uint8)).filter(ImageFilter.MaxFilter(3))
    arr_tinta = np.array(img_tinta, dtype=np.float32) / 255.0
    h, w = arr_tinta.shape
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [244, 239, 230] # Manilha #F4EFE6
    mask = arr_tinta > 0.3
    poster[mask] = [67, 44, 122] # Violeta #432C7A
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

mimeografo_shader.glsl
// Fragment Shader Mimeógrafo Violeta
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    float l = dot(texture2D(u_tex, v_uv).rgb, vec3(0.299, 0.587, 0.114));
    vec3 colManilha = vec3(0.957, 0.937, 0.902); // #F4EFE6
    vec3 colVioleta = vec3(0.263, 0.173, 0.478); // #432C7A
    gl_FragColor = vec4(l < 0.6 ? colVioleta : colManilha, 1.0);
}
