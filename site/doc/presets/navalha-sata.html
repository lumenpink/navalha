1. Memorial Histórico & Contexto Contracultural

Evoca a mítica e indomável figura de Madame Satã nos cortiços e cabarés da Lapa boêmia carioca do início do século XX. O contraste áspero do entalhe em madeira e linóleo popular reflete a malandragem indócil, o capoeirista imbatível e a resistência de corpos negros e dissidentes contra a repressão policial da Primeira República.

★ Memória & Legado — Madame Satã (João Francisco dos Santos, 1900–1976)

Memória & Legado — Madame Satã (João Francisco dos Santos, 1900–1976): Artista, cozinheiro, malandro lendário e símbolo monumental de resistência e insubmissão na Lapa do Rio de Janeiro. Negro, homossexual e de destreza física avassaladora na capoeira, Satã encarava cordões inteiros de policiais armados e transformou a perseguição cotidiana em mito revolucionário. Criador de performances teatrais e personificação da audácia periférica, seu nome ecoa na cultura brasileira como a encarnação viva de quem nunca abaixou a cabeça para o poder opressor.

3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Opera com segmentação estrita por luminância e difusão de erro Atkinson acentuada com filtro unsharp de 3.0x. A paleta tricromática em carvão linóleo e ouro queimado sobre papel kraft resgata o corte dramático da gravura popular e o fio cortante de navalhas no calcanhar.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Unsharp Mask (r=1.8, k=2.8) + Queima de Níveis Severa (Min=20, Max=235).

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Atkinson Dithering com Queima Tonal de Xilogravura

Atkinson 75% com threshold de corte ajustado para linóleo escuro: Dispersão de 1/8 nos 6 pontos canônicos: [ x+1, y ], [ x+2, y ], [ x-1, y+1 ], [ x, y+1 ], [ x+1, y+1 ], [ x, y+2 ] Quantização em 3 tons estritos: Carvão #1A1412, Ouro Cru #D4883A, Branco #FFFFFF

Particularidade do Preset: Textura de gravura popular talhada em linóleo; contraste brutal que enaltece a musculatura e o corte do olhar sobre dourado queimado.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_navalha_sata.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image, ImageFilter

def atkinson_dither(gray: np.ndarray) -> np.ndarray:
    h, w = gray.shape
    buf = gray.astype(np.float32)
    out = np.zeros((h, w), dtype=np.uint8)
    for y in range(h):
        for x in range(w):
            val = buf[y, x]
            q = 255.0 if val >= 128.0 else 0.0
            out[y, x] = int(q)
            err = (val - q) / 8.0
            if x + 1 < w: buf[y, x + 1] += err
            if x + 2 < w: buf[y, x + 2] += err
            if y + 1 < h:
                if x - 1 >= 0: buf[y + 1, x - 1] += err
                buf[y + 1, x] += err
                if x + 1 < w: buf[y + 1, x + 1] += err
            if y + 2 < h: buf[y + 2, x] += err
    return out

def render_navalha_sata(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    gray = img.convert('L')
    blur = gray.filter(ImageFilter.BoxBlur(1.8))
    arr_gray = np.array(gray, dtype=np.float32)
    unsharp = np.clip(arr_gray + 2.8 * (arr_gray - np.array(blur, dtype=np.float32)), 0, 255)
    levels = np.clip((unsharp - 20.0) / 215.0 * 255.0, 0, 255)
    dithered = atkinson_dither(levels)
    h, w = dithered.shape
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [212, 136, 58] # Fundo Ouro Cru #D4883A
    poster[dithered == 0] = [26, 20, 18] # Carvão #1A1412
    poster[(dithered == 255) & (arr_gray < 220)] = [255, 255, 255] # Branco #FFFFFF
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

navalha_sata_shader.glsl
// Fragment Shader Navalha Satã
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    vec4 c = texture2D(u_tex, v_uv);
    float l = dot(c.rgb, vec3(0.299, 0.587, 0.114));
    l = clamp((l - 0.08) / 0.84, 0.0, 1.0);
    vec3 colCarvao = vec3(0.102, 0.078, 0.071); // #1A1412
    vec3 colOuro   = vec3(0.831, 0.533, 0.227); // #D4883A
    vec3 colBranco = vec3(1.0, 1.0, 1.0);
    if (l < 0.38) gl_FragColor = vec4(colCarvao, 1.0);
    else if (l > 0.88) gl_FragColor = vec4(colOuro, 1.0);
    else gl_FragColor = vec4(colBranco, 1.0);
}
