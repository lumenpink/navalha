3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Retícula matricial ordenada Bayer 4x4 combinada com corte de guilhotina e tipografia ampliada de fundo sangrando em vermelho carmesim vibrante (`#B31B1B`). O acabamento de linhas retas e alto contraste tipográfico gera o impacto imediato de cartazes de lambe-lambe de rua.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Unsharp (r=1.5, k=2.2) + Levels (20-235).

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Bayer 4x4 Construtivista

Matriz Bayer 4x4 normalizada: M4 = (1/16) * [ [ 0, 8, 2, 10], [12, 4, 14, 6], [ 3, 11, 1, 9], [15, 7, 13, 5] ] Quantização em Carmesim #B31B1B, Preto Chumbo #111111 e Papel Jornal Cru #E6E2D8.

Particularidade do Preset: Cartaz teatral de agitação e propaganda, blocos tipográficos maciços e estética construtivista operária.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_teatro_operario.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image

BAYER_4X4 = np.array([[0, 8, 2, 10], [12, 4, 14, 6], [3, 11, 1, 9], [15, 7, 13, 5]], dtype=np.float32) / 16.0

def render_teatro_operario(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    gray = np.array(img.convert('L'), dtype=np.float32) / 255.0
    h, w = gray.shape
    tiled = np.tile(BAYER_4X4, (int(np.ceil(h/4)), int(np.ceil(w/4))))[:h, :w]
    dither = np.where(gray >= tiled, 1, 0)
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [179, 27, 27] # Carmesim #B31B1B
    poster[dither == 0] = [17, 17, 17] # Chumbo #111111
    poster[(dither == 1) & (gray > 0.65)] = [230, 226, 216] # Jornal #E6E2D8
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

teatro_operario_shader.glsl
// Fragment Shader Teatro Operário
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
const mat4 b4 = mat4(0.0, 8.0, 2.0, 10.0, 12.0, 4.0, 14.0, 6.0, 3.0, 11.0, 1.0, 9.0, 15.0, 7.0, 13.0, 5.0) / 16.0;
void main() {
    float l = dot(texture2D(u_tex, v_uv).rgb, vec3(0.299, 0.587, 0.114));
    vec2 coord = mod(gl_FragCoord.xy, 4.0);
    float t = b4[int(coord.x)][int(coord.y)];
    if (l < t) gl_FragColor = vec4(0.067, 0.067, 0.067, 1.0); // Chumbo
    else if (l > 0.7) gl_FragColor = vec4(0.902, 0.886, 0.847, 1.0); // Jornal
    else gl_FragColor = vec4(0.702, 0.106, 0.106, 1.0); // Carmesim
}
