1. Memorial Histórico & Contexto Contracultural

Em agosto de 1981, a IBM lançou a placa Color/Graphics Adapter (CGA) para o IBM PC 5150. Equipada com um controlador Motorola MC6845 e míseros 16 KB de memória de vídeo, a placa não tinha capacidade de endereçar livremente cores por pixel em resolução gráfica (320x200). A engenharia da IBM fixou então duas paletas rígidas de 4 cores no hardware (Paleta 1: Preto, Ciano, Magenta, Branco; Paleta 0: Preto, Verde, Vermelho, Amarelo). Essa restrição forçou os primeiros desenvolvedores e artistas a criarem mundos com céus magenta e mares ciano fluorescente, fundando a estética cibernética mais alienígena dos primórdios da microinformática.

★ Memória & Legado — Neon Cunha

Memória & Legado — Neon Cunha: Mulher negra, travesti e ativista independente com décadas de protagonismo nas lutas interseccionais brasileiras. Notabilizou-se internacionalmente ao enfrentar a tutela do Estado brasileiro e reivindicar sua retificação de registro civil sem laudo psiquiátrico ou patologização médica, afirmando de maneira categórica a autodeterminação corporal, a soberania e a dignidade humana.

3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Downsampling forçado para 320 pixels de largura com quantização euclidiana estrita sobre a Paleta 1 CGA em alto brilho. O padrão de retícula utiliza dithering matricial Bayer 4x4 expandido por Nearest-Neighbor 3x, preservando a pureza geométrica crua dos monitores CRT RGB com entrada digital TTL da década de 1980.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 320px (Nearest Neighbor). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Downsampling para 320x200 + Distância Euclidiana em 4 Cores Fixas.

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Bayer 4x4 com Paleta Fixa MC6845 Modo 1

Paleta Estrita de 4 Cores do Chip Motorola MC6845 (1981): Preto: #000000 (0, 0, 0) Ciano: #55FFFF (85, 255, 255) Magenta: #FF55FF (255, 85, 255) Branco: #FFFFFF (255, 255, 255) Dither por matriz Bayer 4x4.

Particularidade do Preset: Homenagem ao primeiro adaptador gráfico colorido do IBM PC 5150 em 1981; 4 cores fluorescentes e pixels esticados.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_cga.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image

CGA_PALETTE = np.array([
    [0, 0, 0],       # Preto
    [85, 255, 255],  # Ciano
    [255, 85, 255],  # Magenta
    [255, 255, 255]  # Branco
], dtype=np.float32)

def render_cga(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img_low = img.resize((320, int(round(h * 320 / w))), Image.Resampling.BILINEAR)
    arr = np.array(img_low, dtype=np.float32)
    # Para cada pixel, encontra a cor CGA mais próxima por distância euclidiana
    dists = np.linalg.norm(arr[:, :, np.newaxis, :] - CGA_PALETTE[np.newaxis, np.newaxis, :, :], axis=3)
    best_idx = np.argmin(dists, axis=2)
    cga_img = CGA_PALETTE[best_idx].astype(np.uint8)
    Image.fromarray(cga_img).resize((720, int(round(h * 720 / w))), Image.Resampling.NEAREST).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

cga_shader.glsl
// Fragment Shader CGA 1981
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    vec3 c = texture2D(u_tex, v_uv).rgb;
    float l = dot(c, vec3(0.299, 0.587, 0.114));
    if (l < 0.25) gl_FragColor = vec4(0.0, 0.0, 0.0, 1.0);
    else if (l < 0.55) gl_FragColor = vec4(0.33, 1.0, 1.0, 1.0); // Ciano
    else if (l < 0.85) gl_FragColor = vec4(1.0, 0.33, 1.0, 1.0); // Magenta
    else gl_FragColor = vec4(1.0, 1.0, 1.0, 1.0); // Branco
}
