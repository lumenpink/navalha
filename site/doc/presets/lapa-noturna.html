1. Memorial Histórico & Contexto Contracultural

Uma homenagem ao submundo boêmio do Rio de Janeiro: a Lapa histórica, as vielas sob os Arcos, luzes de neon refletidas no asfalto molhado após pancadas de chuva de verão e a estética cyberpunk da América Latina periférica.

★ Memória & Legado — Linn da Quebrada (1990–)

Memória & Legado — Linn da Quebrada (1990–): Artista multimídia, cantora, compositora e atriz paulistana. Com os discos antológicos Pajubá (2017) e Traveqa (2021), e sua atuação no cinema e na TV, Linn revolucionou a música popular brasileira contemporânea. Ela ressignificou o corpo travesti como território poético, político e erótico de disputa, quebrando convenções de gênero e normas estéticas com letras complexas, flow afiado e uma presença visual magnética que recusa qualquer tentativa de domesticação cultural.

2. Paleta Cromática Canônica & Mapeamento

O preset reduz estritamente o espaço de cores contínuo da imagem para a seguinte paleta canônica indexada:

Asfalto Sujo
HEX: #0B0B0E
Magenta Neon
HEX: #FF007F
Ciano Elétrico
HEX: #00F0FF

3. Especificação Algorítmica Passo a Passo (Rigor Matemático)

Duotone ácido de alta frequência cromática. Utiliza a difusão de erro clássica de Floyd-Steinberg com Varredura em Serpentina (alternando esquerda-direita e direita-esquerda entre linhas pares e ímpares para aniquilar artefatos lineares). A tipografia recebe distorção vertical forçada de 180% a 220%, ocupando agressivamente a parte aérea do pôster.

Etapa 3.1: Resolução Base & Downsampling

A largura base é parametrizada em 720px (Lanczos3). O redimensionamento deve ocorrer antes da difusão de erro para que os grãos ou blocos de retícula tenham escala física perceptível ao olhar humano.

Etapa 3.2: Tratamento Tonal & Unsharp Masking

Luminância ITU-R BT.601 + Unsharp (r=1.5, k=2.0) + Levels (15-240).

L(x, y) = 0.299 · R(x, y) + 0.587 · G(x, y) + 0.114 · B(x, y)

Etapa 3.3: Algoritmo de Dither & Difusão de Erro / Retícula

Algoritmo Central: Floyd-Steinberg Duotone Neon

Floyd-Steinberg serpentina com mapeamento duotone desacoplado: Meios-tons baixos mapeados para Magenta Elétrico #FF007F. Altas luzes mapeadas para Ciano Ácido #00F0FF. Fundo e sombras profundas em Asfalto Noturno #0B0B0E.

Particularidade do Preset: Contraste vibrante das noites da Lapa carioca e da Santa Cecília paulistana, neon cyberpunk e atrito de rua.

5. Guia de Reimplementação Agnóstica (Código de Referência)

Código autocontido em Python 3 com NumPy e Pillow implementando o núcleo matemático deste preset para você rodar ou portar para outra linguagem:

reimplement_lapa_noturna.py (Python 3 + NumPy) LICENÇA: GPL-3.0 / MIT 
import numpy as np
from PIL import Image, ImageFilter

def render_lapa_noturna(input_path: str, output_path: str):
    img = Image.open(input_path).convert('RGB')
    w, h = img.size
    img = img.resize((720, int(round(h * 720 / w))), Image.Resampling.LANCZOS)
    gray = img.convert('L')
    arr = np.array(gray, dtype=np.float32)
    h, w = arr.shape
    poster = np.zeros((h, w, 3), dtype=np.uint8)
    poster[:, :] = [11, 11, 14] # Asfalto #0B0B0E
    mask_magenta = (arr >= 70) & (arr < 170)
    mask_ciano = arr >= 170
    poster[mask_magenta] = [255, 0, 127] # Magenta #FF007F
    poster[mask_ciano] = [0, 240, 255] # Ciano #00F0FF
    Image.fromarray(poster).save(output_path)

Fragment Shader GLSL (Para Processamento em GPU em Tempo Real)

lapa_noturna_shader.glsl
// Fragment Shader Lapa Noturna
precision mediump float;
uniform sampler2D u_tex;
varying vec2 v_uv;
void main() {
    vec4 c = texture2D(u_tex, v_uv);
    float l = dot(c.rgb, vec3(0.299, 0.587, 0.114));
    vec3 colAsfalto = vec3(0.043, 0.043, 0.055); // #0B0B0E
    vec3 colMagenta = vec3(1.0, 0.0, 0.498);     // #FF007F
    vec3 colCiano   = vec3(0.0, 0.941, 1.0);     // #00F0FF
    if (l < 0.28) gl_FragColor = vec4(colAsfalto, 1.0);
    else if (l < 0.68) gl_FragColor = vec4(colMagenta, 1.0);
    else gl_FragColor = vec4(colCiano, 1.0);
}
