Motor de Determinismo

Hash FNV-1a de 64 Bits, Sementes & Reprodutibilidade Gráfica Estrita

Como o NAVALHA garante artefatos orgânicos de colagem analógica, tremores de fanzine e ondulações senoidais sem recorrer a geradores estocásticos voláteis ou aleatoriedade imprevisível.

1. O Princípio do Anti-Design Determinístico

No ecossistema de artes gráficas, serigrafia, risografia e publicação independente, a reprodutibilidade bit-a-bit é um requisito fundamental:

  • Separação de Cores Fiel: Ao decompor o cartaz em matrizes de impressão (PDFs de fotolito por cor), a geometria, os recortes de tarja e as ondulações precisam coincidir com exatidão micrométrica em cada chapa.
  • Paridade CLI & Web: O mesmo comando executado no terminal headless ou pelo botão do navegador deve entregar uma imagem final idêntica pixel por pixel.
  • Reversibilidade e Testabilidade: Testes de regressão automatizados e testes de sanidade visual exigem hashes de saída constantes para as mesmas entradas.

Por essa razão, o núcleo do Navalha (navalha-core e navalha-cli) recusa qualquer chamada a geradores de números aleatórios estocásticos (como rand::random() ou funções dependentes do relógio do sistema SystemTime::now()). Todas as variações orgânicas e imperfeições táteis são derivadas como funções puras dos dados de entrada.

2. Cálculo da Semente Primária (Hash FNV-1a de 64 Bits)

A semente básica (seed: u64) é extraída diretamente do buffer de pixels da imagem de sujeito tratada (processed_subject) através do algoritmo não-criptográfico de alta dispersão FNV-1a de 64 bits.

Constantes Canônicas FNV-1a (64 bits):
Offset Basis = 0xcbf29ce484222325 (14695981039346656037)
FNV Prime = 0x100000001b3 (1099511628211)

Regra de Acumulação:
hash = (hash ^ byte) * FNV_PRIME (com wrap aritmético de 64 bits)

Etapa 2.1: Varredura de Pixels da Imagem

A função compute_subject_seed(image, fallback_text) itera sequencialmente sobre cada canal de cada pixel RGBA da imagem de entrada:

crates/navalha-core/src/press.rs
pub fn compute_subject_seed(image: Option<&RgbaImage>, fallback_text: &str) -> u64 {
    const FNV_OFFSET_BASIS: u64 = 0xcbf29ce484222325;
    const FNV_PRIME: u64 = 0x100000001b3;

    if let Some(img) = image {
        let mut hash = FNV_OFFSET_BASIS;
        for pixel in img.pixels() {
            for &byte in &pixel.0 {
                hash ^= byte as u64;
                hash = hash.wrapping_mul(FNV_PRIME);
            }
        }
        hash
    } else {
        // Fallback determinístico caso o cartaz não possua imagem
        let mut hash = FNV_OFFSET_BASIS;
        for &byte in fallback_text.as_bytes() {
            hash ^= byte as u64;
            hash = hash.wrapping_mul(FNV_PRIME);
        }
        hash
    }
}

Etapa 2.2: Fallback Determinístico de Tipografia

Quando o cartaz não possui imagem de sujeito carregada (modo estritamente tipográfico), a semente é computada sobre os bytes UTF-8 da manchete/slogan combinados (fallback_text). Isso garante que até mesmo cartazes puramente textuais tenham variações determinísticas e estáveis baseadas nas palavras digitadas.

3. Motor Pseudoaleatório Linear (LCG com Salt)

Para derivar valores independentes para diferentes elementos do cartaz (ex: rotação de cada palavra individual, fase de onda senoidal, ou distribuição de falhas de toner de xerox), utiliza-se o gerador congruencial linear canônico de Donald Knuth (MMIX / 64 bits):

lcg_hash(seed, salt) = seed.wrapping_mul(6364136223846793005) + salt.wrapping_mul(1442695040888963407) + 1

Aplicações Práticas:

  • Rotação Orgânica de Palavras: Cada palavra i recebe o salt i * 7 + 13. O resultado normalizado em $[0.0, 1.0]$ mapeia para o intervalo de rotação $[-\theta_{max}, +\theta_{max}]$.
  • Fase da Onda Senoidal: O salt 101 deriva o deslocamento de fase $\phi$, fazendo com que cada imagem cause uma modulação de onda única no texto, mas 100% reproduzível.
  • Artefatos de Toner da Xerox: Coordenadas $(x, y)$ são combinadas com a semente para calcular riscos verticais e micro-falhas de pó de carbono sem tabelas estáticas.

5. Código de Referência para Reimplementação Agnóstica

Script autocontido em Python 3 reproduzindo a exata lógica matemática de hash FNV-1a de 64 bits e derivação LCG para verificação em testes externos:

deterministic_seed.py (Python 3) LICENÇA: GPL-3.0 / MIT 
def compute_subject_seed(rgba_bytes: bytes, fallback_text: str = "") -> int:
    """Calcula a semente FNV-1a de 64 bits idêntica à do navalha-core."""
    FNV_OFFSET = 0xcbf29ce484222325
    FNV_PRIME  = 0x100000001b3
    MASK64     = 0xFFFFFFFFFFFFFFFF

    if rgba_bytes and len(rgba_bytes) > 0:
        h = FNV_OFFSET
        for b in rgba_bytes:
            h = (h ^ b) & MASK64
            h = (h * FNV_PRIME) & MASK64
        return h
    else:
        h = FNV_OFFSET
        for b in fallback_text.encode('utf-8'):
            h = (h ^ b) & MASK64
            h = (h * FNV_PRIME) & MASK64
        return h

def lcg_hash(seed: int, salt: int) -> int:
    """Deriva pseudoaleatoriedade determinística a partir de uma semente e salt."""
    MASK64 = 0xFFFFFFFFFFFFFFFF
    term1 = (seed * 6364136223846793005) & MASK64
    term2 = (salt * 1442695040888963407) & MASK64
    return (term1 + term2 + 1) & MASK64

def get_word_rotation(seed: int, word_index: int, max_degrees: float) -> float:
    """Calcula o ângulo determinístico para a palavra de índice word_index."""
    salt = word_index * 7 + 13
    rnd = (lcg_hash(seed, salt) & 0xFFFF) / 65535.0  # Normalizado entre 0.0 e 1.0
    return (rnd * 2.0 - 1.0) * max_degrees
